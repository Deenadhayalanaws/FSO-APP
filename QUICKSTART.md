# 🚀 Quick Start Guide - React FSO Sample Diary

## Installation & Running

### 1. Install Dependencies
```bash
cd fso-react-app
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

App opens at: **http://localhost:3000**

### 3. Build for Production
```bash
npm run build
```

Output in `dist/` folder

## Quick Deploy Options

### Option 1: Vercel (Easiest)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

### Option 2: Netlify
```bash
# Install Netlify CLI
npm i -g netlify-cli

# Deploy
netlify deploy --prod
```

### Option 3: GitHub Pages
```bash
npm run deploy
```
